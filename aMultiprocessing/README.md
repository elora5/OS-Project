# Collatz Conjecture Multiprocessing Program

## Problem Description

The Collatz conjecture concerns what happens when we take any positive integer n and apply the following algorithm:
- If n is even, divide it by 2
- If n is odd, multiply it by 3 and add 1

The conjecture states that when this algorithm is continually applied, all positive integers will eventually reach 1.

## Solution Approach

### How I Solved the Problem

1. **Input Validation**: The program first validates that a positive integer is provided as a command-line argument.

2. **Process Creation**: Uses the `fork()` system call to create a child process from the parent process.

3. **Task Distribution**: 
   - The child process generates and prints the Collatz sequence
   - The parent process waits for the child to complete using `wait()`

4. **Error Handling**: Comprehensive error checking for fork failures, wait failures, and invalid input.

5. **Process Synchronization**: The parent process waits for the child to complete before exiting, ensuring proper process coordination.

### Key Features

- **Multiprocessing**: Uses `fork()` to create separate processes
- **Process Isolation**: Parent and child have separate memory spaces
- **Proper Synchronization**: Parent waits for child completion
- **Robust Error Handling**: Handles various failure scenarios
- **Input Validation**: Ensures only positive integers are accepted

6. Exit status information

## Technical Details

### System Calls Used
- `fork()`: Creates a new child process
- `wait()`: Parent waits for child process to complete
- `getpid()`: Gets the current process ID
- `exit()`: Terminates the current process

### Process Flow
1. Parent process starts
2. Parent calls `fork()` to create child
3. Both processes continue execution
4. Child generates Collatz sequence
5. Child exits
6. Parent waits for child completion
7. Parent exits

### Error Handling
- Invalid command line arguments
- Non-positive integer input
- Fork failures
- Wait failures
- Process termination signals
